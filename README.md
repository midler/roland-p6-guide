# Тренажёр Roland P-6

Интерактивный курс по сэмплеру Roland AIRA Compact P-6 на русском языке. Это одна HTML-страница без сборки и зависимостей: её можно открыть в браузере или опубликовать через GitHub Pages.

## Что внутри

- **База** — 11 уроков: от первого звука до моушенов, плюс два урока теории (ритм на 16 шагах, ноты и аккорды на кнопках).
- **Четыре ветки** в любом порядке: биты, саунд-дизайн, живая игра, компьютер и порядок (импорт, MIDI, Ableton, свой пак звуков).
- **Жанровые рецепты**: лоу-фай, эмбиент, драм-н-бейс.
- **Интерактивная схема панели**, сетки битов и схемы аккордов, которые можно послушать в браузере, творческие задания, шпаргалка, видео и ссылки.
- **Режим по шагам** для занятий с прибором в руках и **код прогресса** для переноса отметок между устройствами. Прогресс хранится только в браузере.

## Источники

Все нажатия кнопок сверены с [официальным онлайн-руководством Roland P-6](https://static.roland.com/manuals/p-6/en-US/index.html) (система Ver. 1.02). Приёмы из YouTube-роликов, которых нет в руководстве, помечены в тексте, рядом даны ссылки на ролики с таймкодами.

Roland, AIRA и P-6 — товарные знаки Roland Corporation. Это неофициальный учебный материал, сэмплы Roland в репозиторий не входят.

## Как открыть

### Без интернета (самолёт, метро)

Сайт — это офлайн-приложение (PWA). Один раз откройте его онлайн, после этого он работает без сети:

- **iPhone (Safari):** откройте сайт → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** откройте сайт → меню ⋮ → «Добавить на главный экран» или «Установить приложение».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке, или просто откройте сайт один раз онлайн — дальше он откроется из кэша.

Без интернета не работают только внешние ссылки (руководство Roland, YouTube); шрифты заменятся системными, если не успели загрузиться.

На компьютере можно и без сайта: Code → Download ZIP, распаковать и открыть `index.html` в браузере.

### Онлайн

- Локально: откройте `index.html` в браузере.
- Онлайн: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Через минуту страница будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как устроен репозиторий

- `src/guide.html` — исходник страницы (та же версия, что опубликована на claude.ai).
- `tools/build_site.py` — собирает из исходника самостоятельную страницу: `python3 tools/build_site.py src/guide.html index.html`.
- `index.html`, `sw.js` — готовая страница и офлайн-кэш для браузера и GitHub Pages. Правки вносятся в `src/guide.html`, затем оба файла пересобираются этой командой.
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — чтобы гайд ставился на телефон как приложение. Иконки делает `tools/make_icons.py`.
