# Решения (кратко, по времени)

- Базовые требования: точные нажатия по руководству Ver 1.02, офлайн-PWA, без сбора данных, тексты на русском.
- Первый урок — «Первый звук» (без компьютера), сразу после — бэкап. Метки базы позиционные.
- Мелодии в KYBD (урок 03) идут раньше аккордов; септаккорды связаны с лоу-фай-рецептом.
- Триоли: 12 шагов = `8t` (три шага на долю), у сеток есть `scale`.
- Упражнения «На слух» с A/B, переключение на границе такта без остановки, статус «Звучит A, с нового такта — B», отдельная кнопка «Стоп».
- Сквозной трек базы в банке 2 (2-01…2-05) идёт по порядку уроков 04→08, финал — урок 28 (8 тактов + возврат на 9-м).
- Живая игра начинается с короткой формы (28), итоговый сет (15) — последним.
- 13 жанровых треков, у каждого карта версий, «До/После», карточки старта с середины; общие сравнения (хаус/2-step, сухой/даб, три версии минимала, слепое A/B хаус-даб).
- Синтезированные примеры помечаются «имитация»; настоящие записи с прибора — по желанию пользователя.
- Теория — отдельный раздел (T1 ритм, T2 ноты), показан среди «Навыков»; база 00–08 подряд.
- Страница уроков разделена: Путь / Навыки / Собери трек; слово «ветка» убрано.
- Глубокие ссылки на урок и шаг; ссылки из рецептов ведут на урок.
- Режим по шагам: последний «Готово» (и флажок пробелом) открывает «Проверь на приборе».
- Правки сеток сохраняются в браузере; есть «Вернуть пример».
