# Проект

**Тренажёр Roland P-6** — русскоязычный интерактивный курс по сэмплеру Roland AIRA Compact P-6.
Один статический HTML-файл (ванильный JS), офлайн-PWA.

- Репозиторий: `midler/roland-p6-guide` (ветка `main`, публичный).
- Сайт: GitHub Pages из корня репозитория (`index.html`, `sw.js`).
- Артефакт claude.ai (приватный): https://claude.ai/artifact/Qrocigb2W546WWwHF9SQ3v — публикуется из `src/guide.html`.
- Задачи: GitHub Issues в том же репозитории (их пишет и переоткрывает владелец, часто с комментарием «Результат проверки курса»).

## Правила (обязательные)
- **Нажатия — только по официальному руководству Roland P-6 Ver 1.02** (https://static.roland.com/manuals/p-6/en-US/index.html). Если источник другой — пометить:
  - справка Roland (support.roland.com) → блок «Не из руководства», тип `roland`;
  - форум Elektronauts → тип `com` с припиской «проверь на своём приборе»;
  - идея упражнения из внешнего источника → тип `idea`.
- Работает офлайн. Никакого сбора данных: прогресс в localStorage, перенос — копипаст-кодом.
- Не отправлять личные данные пользователя во внешние сервисы.
- PR не создавать без просьбы. Коммиты сразу в `main`.
- Тексты на русском, на «ты», короткие фразы, без канцелярита. Коды дисплея в ⟨…⟩, кнопки в [ … ].
- Звук в примерах — синтез в браузере; где он заменяет запись с прибора, помечать «имитация» (`sim:1`).

## Пользователь
Владелец P-6, проверяет уроки на приборе короткими сессиями. Длинные чек-листы ему тяжело — давать проверку по 3–4 шага с ответом «да/да/да», результат самому записывать в задачу.

## Дизайн
См. `DESIGN.md`, `PRODUCT.md`, `TYPOGRAPHY.md` в корне. Ключевые правила DESIGN.md: «One Lit Step», «Display Is The Device», «Device Voice», «Hardware-Only Relief». Токены цветов на `:root` (`--accent`, `--done`, `--warn`, `--lcd-ink`…), тёмная тема через `prefers-color-scheme`.
