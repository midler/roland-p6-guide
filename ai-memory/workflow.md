# Порядок работы

1. Правки только в `src/guide.html` (и при необходимости `PRODUCT.md`, `DESIGN.md`).
2. Сборка: `python3 -I tools/build_site.py src/guide.html index.html` → `index.html`, `sw.js`.
3. Проверка синтаксиса данных: `new Function(...)` на кусок `const lessons=[ … ];` (быстро ловит пропущенные скобки).
4. Локальный сервер: `python3 -m http.server 8765` в корне репо.
5. Playwright (Chromium предустановлен): тесты в scratchpad; главный — `checklist.js` (10 пунктов: прокрутка вбок, текст ≥12px, подписи кнопок, цели ≥24px на телефоне, 200% текст, видимый фокус, ошибки консоли, синонимы поиска, «нет сети», reduced motion). Проверять 390×844 и 1280×800, светлая и тёмная тема.
6. Коммит в `main` с трейлером:
   `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и `Claude-Session: …`. `Closes #N` закрывает задачу; `Refs #N` — если нужна проверка на приборе.
7. `git push origin main`.
8. Публикация артефакта: Artifact publish `file_path=src/guide.html` (тот же URL).
