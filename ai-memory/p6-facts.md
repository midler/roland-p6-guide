# Факты о P-6, на которые опирается курс

## Руководство Roland Ver 1.02 (основной источник)
- Детали ноты: держи шаг и жми [GRANULAR] по кругу: нота → v → P → G (0–150) → t (−50…99 % шага) → сабстеп; значение [TEMPO/VALUE].
- Вероятность: P.0–100, P.1st, P. n1, P.x_y; мастер-вероятность [KYBD] + [TEMPO/VALUE] (−100…100, не сохраняется, действует на ноты ≤90).
- Размер шага: держи [PATTERN] + [TEMPO/VALUE] (1_8, 1_16, 1_32, 8t, 16t, 32t). Длина: [SHIFT] + [D♯ · LAST]. Страницы: [SHIFT] + [E/F · PAGE].
- Правка нот: [KYBD] погашен → [●] (⟨St.⟩ и номер) → шаг ручкой/кнопкой → [KYBD] → клавиши (вкл/выкл), [TIE] — лига. До 8 нот в шаге.
- Моушены: держи шаг и крути [PITCH]/[START]/[END]/[LEVEL] на главном экране; CTRL1–3 не пишутся; стереть: [SHIFT] + [OCT− · MOTION] → ⟨CLr.M⟩.
- **Проверено на приборе: параметры меню (MIXER, FILTER, VOICE) в отдельный шаг НЕ пишутся.** Пока меню открыто, горят [A], ENTER, EXIT, шаги нажать нельзя. Эхо «на одном ударе» — только через копию пэда со своим посылом.
- Мьют: [SHIFT] + пэд, [SHIFT] + кнопка банка; хранится в паттерне.
- Сэмплинг: [SAMPLING], пустые пэды мигают; [START] длина (FREE / такты), [END] запуск (t.OFF / SynC / порог).
- Шины: [MFX] + пэд → BUS.A/EFX; [MFX] + [LO-Fi] — вход MIX IN; [MFX] + [GATE] — USB-вход. EFFECT GRAB: [PATTERN] + кнопка эффекта.
- Следующий паттерн начинается, когда доиграет текущий (мигает, пока ждёт).
- Factory reset: держи [KYBD] при включении → ⟨FACt⟩ → [GRANULAR].
- Батарея ≈ 3 ч, зарядка ≈ 3 ч (5 В от 500 мА).

## Проверено владельцем
- Гранулярный фон из секундного слога: [START] 29, [END] 4 (маленькая гранула), ⟨GrnS⟩ 5, ⟨h.SPd⟩ 0, ⟨SPrd⟩ 0 — ровный тянущийся звук.

- **Меню [SHIFT] + кнопка** открывается на первом пункте (VOICE — ⟨C.tUn⟩): [TEMPO/VALUE] выбрать пункт → [C♯ · ENTER] → [TEMPO/VALUE] значение → [C · EXIT] дважды. Запись «→ ⟨x⟩ → ⟨y⟩» в уроках — сокращение этого.
- «Подсмотреть значение»: держи [PATTERN] и крути ручку — только на главном экране; в меню не работает.
- Синт-бас из гласной: петля START 5.107 / END 63, огибающая не нужна.

- Длина записи [START] в сэмплинге: ⟨FREE⟩, ⟨M.1/4⟩, ⟨M.2/4⟩, ⟨M.3/4⟩, ⟨M. 1⟩… — на ⟨M.2/4⟩ ресемпл выходит ~1 с при 110 BPM (владелец на это наткнулся).

## Справка Roland (support.roland.com)
- Версия прошивки: держи [PATTERN] при включении. Обновление: держи [SHIFT] при включении → ⟨UPd⟩ → P6_UPD.BIN → извлечь → [SHIFT] → ждать ⟨OK⟩.
- Возврат заводских сэмплов: [SAMPLING] при включении, BANK_A–D, затем E–H в IMPORT → [KYBD]. Паттерны: [●] при включении → RESTORE → [KYBD].

## Не подтверждено руководством (выведено, стоит проверить)
- ⟨DUPL⟩ ([KYBD] + [OCT+] в правке) для растягивания до 64 шагов.
- Запись аккордов гранулярным пэдом живой записью с лигами.
- Мигание пустых пэдов при смене банка в режиме сэмплинга — **подтверждено владельцем**.
