# Структура курса

Вкладка **Уроки** разделена на три страницы с переключателем сверху (`.subnav`):
- **Путь** (`#lessons`) — общий прогресс, ряд кружков 00–08 («ты здесь»), список уроков базы.
- **Навыки** (`#skills`) — карточки: Теория, Биты, Саунд-дизайн, Живая игра, Компьютер.
- **Собери трек** (`#tracks`) — 13 жанров: BPM, длительность, прогресс, «▶ Слушать» (превью последней версии трека), «Открыть».
Страница раздела — `#branch-<id>`; урок — `#l-<id>`, шаг — `#l-<id>-s<N>` (N с 1), блок «Если все пэды заняты» — `#l-09-full`.

Слово «ветка» из интерфейса убрано (в коде секции по-прежнему `SECTIONS`, страница — `v-branch`).

**Важно про номера.** id урока ≠ метка. Метки базы позиционные: id `01` («Первый звук») показан как 00, id `00` (бэкап) — как 01. Тексты пишут «урок NN» по **id**, функция `relabel()` сама подставляет метку. Свободные id: 29, 73+.

## Жанровые треки
Все используют **банк 4** (4-01…4-04; если занят — бэкап или 4-09…4-16). Итог каждого — запись/форма. В первом уроке трека — карта версий и финала (`overview`, `final`).
